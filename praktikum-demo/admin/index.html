Открыть сайт ↗
Сайт на GitHub оставлен без изменений. Эта админка читает именно его, позволяет менять данные, смотреть предпросмотр и собирать новый HTML. Публикацию на GitHub для всех посетителей подключим отдельным защищённым сервером — без токена в браузере.

Курс

Цена и дата старта сейчас на сайте указаны как «уточняйте».

Контакты

Тексты страницы

Редактируются все элементы сайта, помеченные data-content-key. Перенос строки сохраняется как <br>.

Фотографии

Можно заменить встроенные изображения только в черновике/экспорте. Публичный исходник не меняется.

Библиотека

Материалы берутся из JSON-блока site-data текущего сайта.

Тренажёр

Вопросы, варианты и правильные ответы из текущего site-data.

История и копии

Черновики хранятся в этом браузере.
