# Практикум — клиентская демо-версия

- Сайт: https://mafiadjeck-cmd.github.io/praktikum-demo/
- Админка: https://mafiadjeck-cmd.github.io/praktikum-demo/admin/

Сайт и браузерная админка опубликованы через GitHub Pages.

В текущей демо-версии админка сохраняет черновики и историю в браузере, открывает предпросмотр и применяет опубликованные изменения к сайту в том же браузере через localStorage. Для глобального изменения сайта для всех посетителей нужна серверная публикация через защищённый GitHub API/сервер.
